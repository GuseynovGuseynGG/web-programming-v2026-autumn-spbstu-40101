# Лабораторная работа 3

## Задание

Вариант 40. Переместить числовые нули в конец массива, сохранив порядок
остальных элементов.

## Реализация

Функция `moveZerosToEnd(arr)` собирает ненулевые элементы и нули в два массива и
объединяет их. Строгое сравнение сохраняет строку `'0'` и значение `false`
наравне с другими ненулевыми элементами. Исходный массив сохраняется. Время и
дополнительная память — O(n).

## Запуск

В каталоге лабораторной выполните команду. Ожидаемый результат — `[3, 1, 0, 0]`.

```sh
node --input-type=module -e "import {moveZerosToEnd} from './solution.js'; console.log(moveZerosToEnd([0, 3, 0, 1]))"
```
