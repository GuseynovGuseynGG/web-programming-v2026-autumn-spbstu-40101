# Лабораторная работа 2

## Задание

Вариант 40. По дате в прошлом определить, сколько полных минут, часов или дней
прошло до текущего момента.

## Реализация

Функция `timeAgo(date)` вычисляет разность в миллисекундах. От 60 полных минут
результат выводится в часах, от 24 полных часов — в днях. Русскую форму слова
подбирает `Intl.RelativeTimeFormat`.

## Запуск

В каталоге лабораторной выполните команду. Ожидаемый вывод — `5 минут назад`.

```sh
node --input-type=module -e "import {timeAgo} from './solution.js'; console.log(timeAgo(new Date(Date.now() - 300000)))"
```
