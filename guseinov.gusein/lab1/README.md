# Лабораторная работа 1

## Задание

Вариант 40. Сверстать флаг Бангладеша. Красный круг должен оставаться в центре
зелёного прямоугольника при изменении размеров флага.

## Реализация

Полотнище задаёт систему координат для круга. Свойства `top` и `left` помещают
левый верхний угол круга в центр флага, а `translate(-50%, -50%)` смещает его на
половину собственного диаметра. Диаметр составляет 40% ширины полотнища.

## Запуск

Откройте `index.html` в браузере и уменьшите ширину окна.
